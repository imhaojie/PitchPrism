# Judge testing instructions

Public demo: https://imhaojie.github.io/PitchPrism/

No login, payment or API key is needed. This static demo is labelled **LOCAL**. Facts/explanations are generated by the same Python modules as the server; no live Foundry call is made here.

1. Start at **A different picture**, source time 68:00. The latest completed switch travels **35.5 m** on the synthetic pitch.
2. Play/pause. Clock, event trail and statistics follow the original source time through the enhanced cut's pause/replay.
3. Compare **For the analyst** with **For the fan**.
4. Open **Tactical**, follow **Milo Hart**, then return to **The whole pitch**. Player focus emphasizes supplied synthetic coordinates, not optical tracking.
5. Select **Goal**: the excerpt score is **1–0**, Northbridge scenario xG sum **0.60**. Return to **Switch**: score **0–0**, future shot evidence absent.
6. Switch **Source / Enhanced**; the original moment is preserved.
7. Open **source events** to inspect IDs. **Match recap** explicitly includes the whole excerpt and may reveal later events.

Everything is fictional/synthetic. Shot xG is a scenario input; pass distance and accuracy are computed. No speed, full-match possession, official xG or season data is claimed.

To test real Foundry calls, configure/run the dynamic server using the [Azure guide](../../infra/azure/README.md). Select **Explain this moment**, then inspect actual request IDs/tool trace. The initial migration has no verified cloud success.
