01 / EXPLAIN

Microsoft Foundry

Azure OpenAI reads time-bounded match state, inspects cited evidence and submits a story through validation. English prose is separate from deterministic statistics.

read → inspect → validate
02 / CHECK

Azure AI Content Safety

An optional text analysis checks generated headlines and explanations. When enabled, incomplete, unavailable or high-severity analysis blocks that cloud answer.

optional · F0 template
03 / RECORD

Azure Blob Storage

Store a minimized JSON receipt in a private container. No video, model prompts, generated prose or cloud request identifiers are uploaded by this adapter.

private · identity access · 30-day expiry
04 / PROTECT

Azure Key Vault

Optionally resolve an explicitly named server secret at startup. The preferred keyless path uses managed identity; credentials are never sent to the browser.

server-side secret resolution
05 / OBSERVE

Application Insights

Send a minimal metric for validated explanations and audience mode. Telemetry contains no viewer identity, video, prompts or explanation text.

optional · minimized metrics
06 / HOST

Azure Container Apps

Run the Python API and web player behind HTTPS using a non-root container. The template scales between zero and one Consumption replica.

0–1 replicas · 0.25 vCPU / 0.5 GiB
07 / AUTHENTICATE

Microsoft Entra ID

DefaultAzureCredential supports local Azure CLI identity and hosted managed identity. Optional resource roles scope model, moderation and receipt access.

keyless authentication
